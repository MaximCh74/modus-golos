# Очередь новой сессии «Модус Голос» (сообщения владельца 12.11.2026, 19:46–19:53, дословно по сути)

Правила те же: одна сессия без роёв; ключи из .env в чат не писать; без эмодзи, без цветов вне токенов, без нативных элементов браузера,
без горизонтальной прокрутки; дев-базу не пересеивать, после изменения демо-данных — новый снапшот без личных данных; «Готово» только со
скринами; после каждого пункта — короткий отчёт владельцу.

## 1. Подсказки и «Справка»
- Рядом с каждой метрикой, строкой «Требуют внимания», настройкой (сроки, пороги, баллы, веса лиги) и непонятным полем — иконка «?» (Lucide),
  по нажатию поповер с 1–2 фразами простым языком. Без жаргона: не «SLA», а «срок первого ответа»; не «кластер», а «похожие обращения».
- Страница «Справка» в панели (директор, ответственные, админ): термины по разделам — обращения и стадии, роли и права, сроки и напоминания,
  совещания, баллы и награды, лига, Битрикс24; 1–3 строки на термин.
- Все тексты — из одного словаря терминов, того же, что в промптах ИИ.
- У сотрудника в приложении «Мои поручения» на видном месте со счётчиком невыполненных.

## 2. «Директор в кармане» — отдельный вход для директора
- Маршрут /boss — отдельная PWA: свой манифест «Модус Голос · Директор», своя иконка, start_url /boss, доступ только директору.
- Один экран без прокрутки на телефоне: приветствие ИИ по имени-отчеству (1–2 фразы); переключатель «Сегодня / Неделя»; четыре крупные
  цифры — пришло, решено, ждут вашего решения, просрочено (нажатие — короткий список, у решений «Принять / Отклонить»); большая кнопка
  микрофона «Спросить» + поле текста; ссылка «Подробнее на сайте».
- Вопросы, только чтение: голос/текст → LLM в intent из белого списка (что нового за период; что ждёт моего решения; кто просрочил; главные
  темы; что по городу X; что по обращению A-0XX; как дела у отдела X) → факты считает сервер → LLM пересказывает → каждое число сверяется
  с фактами, иначе шаблон. Неизвестный вопрос — «Не знаю, вот где посмотреть» + ссылка. Ответ голосом и текстом.
- Команды — существующие, с обязательным подтверждением. Голос ответа — нейтральный TTS, голоса реальных людей не клонировать.
- Тесты: каждый тип вопроса, сверка чисел, неизвестный вопрос.

## 3. Главная кнопка — новый стиль (вариант 2 «Акцентный» на картинке кнопка_Отправить_варианты_нужен_вариант_2.jpg)
- Основа — фирменный тёмно-синий, красный бренда мягко появляется в правом нижнем углу (диагональный градиент, красный ~20–25 % ширины).
  Текст и иконка белые и всегда на синей части. Тонкий светлый блик по верхнему краю, мягкая тень.
- Состояния: hover — красная зона плавно чуть растёт (200 мс); active — темнее, тень меньше; disabled — плоский серый без градиента;
  focus — видимая рамка.
- Все цвета градиента — через токены (новый токен для фона главной кнопки), тест на «сырые» цвета не ломать.
- Применить ко всем главным кнопкам: «Отправить», «Подать обращение», «Выполнить», «Принять», «Сообщить о ходе» и т. д. Сплошных красных
  кнопок больше нет. Вторичные — контурные. Отказ/удаление — нейтральные, не красные.
- Красный остаётся: метки на карте, логотип, короткая черта у заголовков, точка просрочки.
- Сначала три варианта (угол и доля красного) на /design, скрины владельцу — он выберет, потом раскатывать везде.

## 4. Остальные экраны этапа 9 (stage9_simplify_tz.md): статус обращения, совещание, профиль, лига, награды — по тем же правилам.

## 5. APK и ТЗ в репозитории
- APK для Android из PWA /app и /boss (Trusted Web Activity, Bubblewrap/PWABuilder) + /.well-known/assetlinks.json на нашем домене, чтобы
  не было адресной строки. Подписанный APK — в demo/, инструкция установки — в отчёт. iOS — только PWA, App Store — в роадмап.
- Все наши ТЗ — в docs/tz/ по порядку этапов (файлы владелец пришлёт). Перед коммитом убрать настоящие имена и ники людей, кроме
  «Сергей Михайлович»: сотрудника заказчика называть «сотрудник заказчика», GitHub-ники не указывать.
