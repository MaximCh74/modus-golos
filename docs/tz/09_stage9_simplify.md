**Задача этапа:** не добавлять, а **убирать с глаз**. Функционал и API не трогаем — второстепенное прячем.

## Правила (для всех экранов, сейчас и дальше)

1. **Нет горизонтальной прокрутки.** Никогда, ни на 1280px, ни внутри Битрикса.
2. **Один экран — один вопрос.** Очередь отвечает на «что мне сделать сейчас?», главная директора — на «что требует моего внимания?».
3. **Одно главное действие на экран** (красная кнопка). Остальные действия — в меню «…» (иконка Lucide).
4. **Нули и пустое не показывать:** «без ответственного: 0», пустые метки, пустая поддержка.
5. **Подписи-пояснения вроде «пересказ ИИ»** — маленькая иконка с подсказкой при наведении, не цветной бейдж.
6. **Цвет:** красный — только главная кнопка, метки карты и просрочка (маленькая точка). Остальное — тёмно-синий и серые.

## 1. Очередь обращений

### 1.1 Колонки по умолчанию — четыре

| Колонка | Что внутри |
|---|---|
| **Обращение** | номер + одна строка «Коротко» (обрезка в 1 строку); тип — маленькая иконка перед номером, высокий приоритет — маленькая метка |
| **Статус** | чип |
| **Ответственный** | аватар + имя (имя в одну строку, фамилия — инициалом, если не влезает) |
| **Возраст** | «2 дн»; при просрочке — красная точка слева |

Число поддержек — маленький значок с цифрой в первой колонке, только если больше 0.

### 1.2 В карточку

Категория, филиал, подразделение, «новость автору», метки, оценка автора, приоритет.

### 1.3 Кнопка «Вид»

Можно включить дополнительные колонки, выбор сохраняется у пользователя. По умолчанию — четыре.

### 1.4 Строки

Высота строки — одна строка текста, без переносов. Ховер подсвечивает строку, клик открывает карточку.

## 2. Фильтры

### 2.1 Сверху — только две вещи

- **Поиск** (номер или текст).
- **Вкладки:**
  - **«Требуют внимания»** — по умолчанию: просроченные, без ответственного, «мешают работать сейчас», ожидают уточнения;
  - **«Все открытые»**;
  - **«Мои»**;
  - **«Закрытые»**.

### 2.2 Кнопка «Фильтры»

Открывает боковую панель с остальным: филиал, подразделение, категория, статус, ответственный, срок, сортировка.

### 2.3 Активные фильтры

Чипами под вкладками, у каждого крестик. «Сбросить всё».

### 2.4 Счётчик над таблицей

Одна короткая строка: «5 обращений · 2 просрочено». Нули не показываем.

## 3. Карточка обращения

### 3.0 Размещение (баг от сотрудника заказчика)

На скрине сотрудника заказчика: при открытой карточке справа колонка очереди сжимается до одной буквы.
- **Правило:** таблица никогда не сжимается из-за карточки.
- Если ширины хватает на таблицу и карточку — карточка справа.
- Если не хватает (≤1440px, внутри Битрикса, планшет) — карточка открывается **выезжающей панелью поверх таблицы** с затемнением, закрывается крестиком, клавишей Esc и кликом мимо.
- **Проверить** с открытой карточкой: 1280, 1440 и внутри Битрикса.

### 3.1 Сверху

Номер, статус-чип, узкий трекер стадий (стадии для автора — словами собственника, как сейчас).

### 3.2 «Коротко»

Главный блок. Бейдж «пересказ ИИ» заменить маленькой иконкой с подсказкой.

### 3.3 Одна главная кнопка — по статусу

| Статус | Главная кнопка |
|---|---|
| Новое | «Взять в работу» (или «Назначить», если ответственного нет) |
| Ожидает уточнения | «Напомнить автору» |
| В работе | «Сообщить о ходе»; рядом вторичная «Готово» |
| На рассмотрении | «Принять решение» (открывает варианты: в работу / отклонить / к директору) |

### 3.4 Меню «…»

Остальные действия: переназначить, сменить статус вручную, приоритет, запросить уточнение, к директору, «Пересказать заново».

### 3.5 Блок «Подробности», свёрнутый

Автор, филиал, подразделение, категория, оценка автора, приоритет, поддержка, последняя новость, время ответа.

### 3.6 Остальное

«Показать полностью» (исходный текст) и «История» — свёрнуты.

## 4. Внутри Битрикса (iframe)

Компактный режим, когда страница открыта внутри портала:
- **без нашей шапки с логотипом** — Битрикс уже пишет «Модус Голос» сверху;
- навигация — компактные вкладки в одну строку;
- отступы меньше;
- вёрстка рассчитана на ширину фрейма, без горизонтальной прокрутки.

Проверить на реальном портале.

## 5. Главная директора

Включает отложенные замечания из этапа 8, §5.

- **Цифры:** четыре плитки вместо шести — открытые, доля рассмотренных, среднее время ответа, реализовано за месяц. «Просрочено» и «Без ответственного» уходят в строку «Требуют внимания».
- **Убрать:** красные верхние полосы у плиток, оранжевые чипы, зелёный бейдж.
- **ИИ-сводка — до 3 строк.** Длинные перечисления сворачивать: «из 5 городов», а не список городов. Кнопки «Озвучить», «Обновить»; «шаблон» убрать в меню «…».
- **«Команда» (Джарвис):** поле + микрофон в одну строку, без поясняющего текста над ним (подсказка — плейсхолдером).
- **«Требуют внимания»** — одна компактная строка-ссылка с числами: «просрочено 2 · ждут решения 2 · без новостей 3 · мешают работать 7».
- **Карта:** чуть темнее подложка; карточка города — лёгкое размытие фона, QR на плотной подложке.
- **Шапка:** «Модус Голос». Слово «демо» — только мелко в подвале.
