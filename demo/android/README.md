# Android-приложения (TWA) для демо

| Файл | Приложение | Пакет | Открывает |
|---|---|---|---|
| `modus-golos.apk` | Модус Голос | `kz.cqsystems.modusgolos` | https://modus.cq-systems.kz/app |
| `modus-golos-director.apk` | Директор | `kz.cqsystems.modusgolos.boss` | https://modus.cq-systems.kz/boss |

Подписаны демо-ключом владельца (отпечаток — в `web/.well-known/assetlinks.json`). Android 7.0+ и Chrome на телефоне.
Установка: передать файл на телефон → открыть → разрешить установку из этого источника → установить. Подробно — `docs/ANDROID.md`.
